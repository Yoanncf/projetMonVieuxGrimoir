Mon Vieux Grimoire

API REST de référencement et de notation de livres (Node.js, Express, MongoDB).
Elle fournir les données au front-end React fourni, dans le dossier front-end-grimoire.

Lancement

Il faut créer un fichier .env à la racine du projet  back-end-grimoire.
Dans le .env il faut renseigner ces variables : MONGO_URI (dans DATABASE -> Clusters -> connect -> Drivers -> partie 3)  et JWT_SECRET 



cd back-end-grimoire
npm install
npm start
